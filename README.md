# Wire — міні IT-новинний хаб

Тягне RSS з кількох сайтів, сортує за "важливістю" (безкоштовна логіка на
основі свіжості + ключових слів) і показує однією стрічкою в браузері,
з опціональними сповіщеннями.

## Запуск локально

```bash
npm install
npm start
```

Відкрити http://localhost:3300

Сервер сам підтягує новини при старті та потім раз на годину.

## Додати/прибрати сайт

Відредагуйте `feeds.json` — просто масив `{ id, name, url }`, де `url` —
пряме посилання на RSS-стрічку сайту. Перезапустіть сервер.

Зараз підключені: TechCrunch, AIN.UA, SPEKA, The Verge.

⚠️ **Примітка про DOU.ua** (якщо колись захочете додати назад): єдиної
загальної RSS-стрічки на сайті немає, є лише стрічки по тегах, і вони
справді працюють як RSS (перевірено, наприклад
`dou.ua/lenta/tags/provectus/feed/` віддає коректний XML):

1. Відкрийте https://dou.ua/lenta/tags/ — це повний список тегів сайту.
2. Знайдіть теги, які вам цікаві (наприклад "фінансування", "продукт",
   "безпека").
3. Допишіть до URL тега `/feed/` в кінці — вийде стрічка типу
   `https://dou.ua/lenta/tags/<тег>/feed/`. Перевірте у браузері —
   має відкритись XML.
4. Додайте потрібні теги в `feeds.json`, кожен окремим об'єктом
   `{ "id": "dou-XXX", "name": "DOU · XXX", "url": "..." }`.

## Як рахується "важливість"

У `server.js`, функція `scoreItem()`:
- 60% ваги — свіжість (новіше = вище, згасає до 0 за ~72 год)
- 40% ваги — збіги зі списком `BOOST_KEYWORDS` (редагуйте під себе)

Це повністю безкоштовний варіант без AI. Якщо згодом захочете розумніший
відбір — замініть `scoreItem()` на виклик Claude API (передати заголовок +
summary, попросити оцінку важливості 0-1). Коштуватиме приблизно $1-2/міс
при 4 джерелах.

## Сповіщення

Кнопка "Сповіщення" вгорі просить дозвіл браузера і потім показує
нативні push-повідомлення для нових новин з високим скором (≥0.55), поки
вкладка відкрита. Це MVP-варіант без сервера — працює, поки браузер
запущений. Якщо захочете сповіщення навіть коли сайт закритий (справжній
Web Push або Telegram-бот на додачу) — це наступний крок, скажіть і
допишу.

## Деплой безкоштовно

- **Render.com** або **Railway.app** — є безкоштовний tier для Node.js
  проєктів, підключаєте GitHub-репозиторій і воно саме деплоїться.
- Або тримати запущеним локально / на Raspberry Pi, якщо хочете 100%
  без хмари.
